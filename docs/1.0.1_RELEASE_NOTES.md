# Website Core 1.0.1

Released 2026-10-23. This maintenance release repairs the authenticated admin
failure possible after newer core files are uploaded over an existing database
without using Admin → Updates.

## Fixed

- Installed-site boot checks the bundled core schema marker before services
  run. If the database is behind, pending core migrations are applied using the
  existing journal and migration lock before the dashboard loads.
- Manual file-manager updates on ordinary shared hosting no longer leave the
  login screen working while authenticated admin pages fail on missing tables
  or columns.
- The reference shown on a production error page now appears in the matching
  PHP error-log line and in `storage/logs/application.log` when the configured
  private storage directory is writable.
- The production error page is responsive and styled instead of returning an
  unformatted HTML fragment.

## Updating an affected installation

Upload the 1.0.1 update over the existing site files. Do not replace generated
configuration, private storage, uploads, or installed package directories. On
the first request, core applies any pending database migrations before loading
the admin dashboard. Refresh `/admin` and sign in normally.

This release does not change Module API version 1 or the independent catering
industry-module version.
