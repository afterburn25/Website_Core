# Website Core 1.0.0

Released 2026-10-23. This is the first stable universal core for Cajun Web
Pro industry sites. It supports ordinary shared hosting, keeps industry logic
in installable modules, and requires no license key for a core-only install or
the explicitly labeled testing bundle.

## What ships in core

- A polished HTTPS-only installer with a live database test, reinstallation
  support, external protected runtime paths, and repeated self-cleanup. If the
  host prevents cleanup, the site stays fail-closed until `install.php` and
  `install/` are manually removed and rechecked.
- Owner/admin/editor authentication, MFA and recovery codes, active-session
  revocation, rate limits, CSRF protection and owner-safe security policies.
- Responsive, persistent, collapsible core administration navigation. Each
  installed industry module contributes its own labeled navigation category.
- Pages with revisions, preview links, scheduled publishing/unpublishing,
  duplication, trash/restore, SEO fields, reusable sections, redirects and
  editable menus with ordered submenu nesting.
- Shared media, safe image variants/replacement, logo/favicon/social imagery,
  theme colors and design tokens.
- Package lifecycle management, isolated module services, dashboard/search/
  health hooks, version compatibility checks and protected `core/base` state.
- Backups, protected-media restore, pre-restore safety snapshots, maintenance
  mode, job/mail operations, diagnostics, audit history and signed updates.
- Aggregated 404 insights, sitemap/robots support, structured data and
  explicit opt-in ETag caching for anonymous core pages. Forms and previews
  remain private/no-store.

## Required Cajun Web Pro attribution

Core injects the following code-owned footer into every public HTML response:

> Website Design & Development by Cajun Web Pro LLC  
> Want a website like this for your business? Let’s build yours.

“Cajun Web Pro LLC” and “Let’s build yours.” link to
`https://cajunwebpro.com`. This attribution is intentionally not editable
through settings, themes, or the supported module API.

## Updating from 0.1.14-dev

1. Create and download a complete backup.
2. Enable maintenance mode in Admin → Operations.
3. Upload `Website-Core-1.0.0-UPDATE.zip` in Admin → Updates.
4. Review the target version and manifest, then apply it. The updater creates
   its own file backup, runs pending migrations, records the action and resets
   OPcache.
5. Disable maintenance mode and verify public pages, admin, menu nesting,
   scheduled content, media, SEO, operations and the required footer.

The update manifest supports cumulative upgrades beginning at `0.1.14-dev`.
It never overwrites generated config, installed locks, runtime storage,
uploads, or installed industry/theme directories.
