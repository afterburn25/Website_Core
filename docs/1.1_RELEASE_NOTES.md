# Website Core 1.1.0

Website Core 1.1 introduces a structured visual page composer while retaining
the legacy sanitized HTML body for existing sites.

## Page composer

- Eleven core block types: hero, rich text, image/text, gallery, call to
  action, testimonials, FAQ, statistics, logo strip, contact and spacer.
- Add, edit, drag, move, hide and remove blocks from the page editor.
- Responsive full-width rendering through the base theme.
- Server-side schema validation, URL allowlisting and HTML sanitization.
- Block documents are included in page revisions, revision restore and page
  duplication.

## Industry integration

Enabled packages can call `ModuleContext::pageBlock()` to register their own
field schema and renderer. Custom blocks appear inside the same core composer
and retain package ownership metadata.

The Module API major remains version 1.
