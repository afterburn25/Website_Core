# Website Core 1.2.0

Website Core 1.2 adds a reusable, industry-neutral forms platform.

- Administrators visually create and reorder text, email, telephone, number,
  date, textarea, select and checkbox fields.
- A Form page-builder block places a saved form on any core page.
- Public submissions require a session CSRF token and are protected by a
  honeypot and bounded IP-scoped rate limit.
- Values are validated and stripped of markup before storage. Checkbox consent
  decisions are retained separately as evidence.
- The admin submission inbox supports form filtering, read state and CSV
  export. Archiving stops new submissions without deleting old entries.
- Optional notification emails use the existing deduplicated system-mail queue.

Pages containing forms remain private/no-store and are never placed in the
anonymous HTML cache.
