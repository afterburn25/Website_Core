# Website Core 1.3.0

Version 1.3 turns the media screen into an organized production library and
introduces a shared visual status-page system.

## Media workflow

- Search by filename, alt text or caption and filter by folder or tag.
- Move and tag several selected assets in one action.
- Store normalized tags and reusable folder organization.
- Set image focal points and request deterministic cropped derivatives.
- Inspect recorded usage references before replacing or deleting an asset.
- Preserve the existing private/public boundary and safe upload validation.

## Visitor-facing system pages

- Branded, responsive 403, 404, 500, maintenance and license-status pages.
- Inline illustrated artwork and critical CSS keep pages polished even while
  themes, databases or ordinary assets are unavailable.
- A deliberately quiet lock icon links owners to the administrator sign-in.
- Error references remain visible and match the private application log.
- Reduced-motion, noindex and semantic accessibility behavior are built in.
