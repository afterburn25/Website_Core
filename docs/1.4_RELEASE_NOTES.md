# Website Core 1.4.0

- Save any block-built page as a reusable layout pattern.
- Apply patterns to existing pages as drafts while preserving the prior layout
  as a recoverable revision.
- Select classic, centered or compact headers and centered, split or minimal
  footers from Appearance.
- Theme manifests may declare an `extends` parent; template resolution falls
  back through active theme, parent theme and the protected base theme.
