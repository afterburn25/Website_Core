# Website Core 1.5.0

- Added an accessible cookie-choice banner with a persistent essential-only
  or analytics preference.
- Google Analytics 4 and Plausible scripts are created only after explicit
  analytics consent; configured identifiers are format-validated.
- Added a public, CSRF-protected and rate-limited privacy request form for
  access, correction and deletion requests.
- Added a private admin request inbox, completion tracking and CSV export.
