# Website Core 1.7.0

- Added a language registry using normalized BCP-47-style locale codes.
- Added translated titles, slugs, body content, blocks, search metadata and
  page schema without duplicating the source page record.
- Added public localized URLs under `/l/{locale}/{slug}`.
- Added localized fallback navigation, language-switch links and `hreflang`
  metadata for translated pages.
- Industry modules remain free to ship their own interface catalogs through
  the existing layered translation API.
