# Website Core 1.8.0

- Owners can create custom administrator roles from the complete core and
  module capability registry. Built-in roles remain protected.
- Publishing is a distinct capability: editors can create and revise content
  but cannot publish, unpublish, or schedule it.
- Editors can submit a draft with a reviewer note. Approval and publishing
  record the responsible administrator and time in the page workflow state.
- Revisions can be compared side by side before a prior version is restored.
- Existing installations are upgraded additively by migration
  `2026_10_23_0019`; the Module API remains version 1.
