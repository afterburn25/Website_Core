# Website Core 1.9.0

- Owners can mint scoped bearer credentials for the versioned `/api/v1`
  health and page endpoints. The plain credential is displayed once; only a
  SHA-256 hash is retained, and revocation is immediate.
- HTTPS webhooks support page, review and backup lifecycle events. Delivery is
  durable through the core queue, payloads carry HMAC-SHA256 signatures, and
  signing secrets are encrypted with the installation key.
- The Integrations screen exports and merges portable page, menu, translation
  and presentation data without transferring administrators, credentials,
  submissions or private operational records.
- Local backups can optionally replicate to an HTTPS WebDAV destination.
  Remote credentials live only in protected `config.php`.
- Migration `2026_10_23_0020` is additive and the Module API remains version 1.
