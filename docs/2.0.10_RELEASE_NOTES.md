# Website Core 2.0.10

Released 2026-10-24.

## Shared-host controller recovery

- Health, Diagnostics, Audit, and Core Updates now route through the fresh
  `Admin\\Controllers\\SystemToolsController` class and file.
- The new class path prevents a shared-host PHP OPcache/autoloader from
  continuing to execute a stale cached `SystemController` after a hosting-panel
  repair upload.
- The Updates workspace retains the 2.0.9 recovery boundary for unreadable,
  invalid, stale, or undeletable staging files and journals.

The repair upload remains installer-free and preserves runtime configuration,
storage, uploads, modules, and database data.
