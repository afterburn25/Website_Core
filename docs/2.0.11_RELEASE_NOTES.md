# Website Core 2.0.11

Released 2026-10-24.

## Version-keyed PHP code-cache refresh

- Bootstrap compares the deployed Core version with the private
  `config/.runtime-code-version` marker before loading Application.
- When the version changes, Core calls `opcache_reset()` when available and
  force-invalidates every PHP file under `core/` and `admin/`, plus the public
  entry files.
- The marker is written only after the best-effort refresh. If the host blocks
  the marker write, Core safely retries on the next request.
- This prevents shared hosts with disabled OPcache timestamp validation from
  combining a new bootstrap/version with stale routing and controller classes.

The repair upload remains installer-free and preserves configuration, storage,
uploads, installed modules, and database data.
