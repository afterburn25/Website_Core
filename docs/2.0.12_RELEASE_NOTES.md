# Website Core 2.0.12

## Shared-host runtime repair

This release removes the final dependency on shared-host OPcache controls.
Bootstrap loads the Core autoloader from a private version-specific path, and
that autoloader does the same for every Core and administration PHP class.
Changing the Core version therefore changes the required pathname and forces
PHP to compile the files that were actually uploaded, even when timestamp
validation and cache-reset functions are disabled by the host.

## Actionable administrator errors

An authenticated administrator who reaches an admin-only HTTP 500 page can
expand technical details containing the exception type, message, source file,
and line. Unauthenticated and public requests continue to see only an opaque
reference. Application logging now falls back from the configured storage
directory to the private configuration directory when necessary.

## Deployment

Extract the matching `REPAIR-UPLOAD` archive into the installed site's root and
overwrite existing files. Configuration, storage, uploads, and the installed
module state are excluded from the repair archive.
