# Website Core 2.0.15

Version 2.0.15 completes the Media workspace's commercial-safety pass. It
improves an existing Core function without adding a new product domain.

## Reference-aware media

Page blocks and page social-sharing images now register their Media-library
references. A file's details identify each referencing page and link directly
to its editor. Referenced-file deletion therefore warns from current page data
instead of relying only on branding references.

Creating, editing, duplicating, and restoring a page synchronizes its media
references. Permanently purging a page removes its reference records. The Core
upgrade migration backfills existing pages, so administrators do not need to
open and resave older content.

## Private image previews

Authorized administrators can now see generated thumbnails and focal-point
previews for private images. The same variant URLs remain forbidden to visitors
without Media-management permission, and private responses use `no-store`
caching. This does not make a private original or derivative public.

## Media workspace

- Uploads announce the chosen filename and size before submission.
- Bulk actions stay unavailable until one or more files are selected; Select
  page reflects checked, unchecked, and partially checked states.
- Details provide a stable URL copy action and explain private URL access.
- Focal points use horizontal and vertical sliders with a live crop marker.
- Opening one details panel closes another, keeping dense libraries manageable.

## Upgrade

Upload the 2.0.15 repair/update package over the installation or apply the
official Core update through **System → Core updates**. The version change
refreshes Core's private runtime-code mirror on shared hosting. Configuration,
storage, uploads, themes, and industry-module data are preserved.
