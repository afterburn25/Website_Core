# Website Core 2.0.16

Version 2.0.16 completes the Navigation workspace's commercial-polish pass.
It improves the existing Core-owned header, footer, and redirect workflows
without adding a new product area.

## Precise visual menu editing

Dragging over the top, center, or bottom of a link now places the moving link
before, beneath, or after that link. Clear insertion treatments show the result
before dropping. Up, down, indent, and outdent buttons provide the equivalent
keyboard-accessible workflow, and Core rejects structures beyond its supported
depth.

Structure changes remain deliberately separate from link details. The editor
requires the new order to be saved or discarded before adding, editing, or
removing another link, preventing a detail save from silently losing an
unsaved drag operation.

## Link visibility and destinations

Every menu item can be visible or staged as hidden. A hidden parent also hides
its submenu publicly while remaining editable in administration. Existing
links remain enabled automatically during upgrade, and site transfers preserve
the visibility choice.

New links can be placed beneath a chosen parent immediately. Managed pages,
internal paths, page anchors, HTTPS destinations, email links, and telephone
links are supported with bounded validation. Same tab, New tab, and New window
targets now survive Core's public-navigation mapping correctly.

## Public navigation and redirects

Core's base theme marks the current internal route. When an administrator has
configured a menu but hidden every link, Core respects that choice instead of
falling back to every published page. Removing a parent link promotes its
children one level in the same location and normalizes their order.

Existing redirects can now be edited in place. Duplicate source paths,
missing rows, excessive field lengths, unsafe destinations, and loops return
useful validation rather than a server error.

## Upgrade

Upload the 2.0.16 repair/update package over the installation or apply the
official Core update through **System → Core updates**. Migration
`2026_10_25_0024` adds the visibility field with a visible default, preserving
all existing menus. Configuration, storage, uploads, themes, module data, and
current link order are preserved.
