# Website Core 2.0.18

Version 2.0.18 makes installer self-removal advisory on shared hosts where the
hosting account and PHP-FPM worker do not own the same document-root entries.
This release is included in the directly usable Landscaping Website 1.0.0
TEST-BUNDLE and repair upload.

## Installer behavior

- A failed document-root create, rename, and delete probe appears as a yellow
  warning instead of a required-check failure.
- The warning explains that installation can continue and gives the exact
  File Manager cleanup step for `install.php` and `install/`.
- Successful setup writes and validates `config.php` and `installed.lock`
  before attempting cleanup. Those permanent controls keep setup disabled even
  when the original installer files are owned by the hosting control panel.
- If physical cleanup still fails, the completion screen stays successful,
  shows a yellow manual-cleanup notice, and keeps the website and admin area
  available.
- Later requests continue retrying safe cleanup and remove the pending marker
  automatically when host ownership is repaired.

## Upgrade and packaging

New installations should use the 2.0.18 complete upload or an industry
TEST-BUNDLE. Existing 2.x sites may apply the 2.0.18 repair upload directly;
this release has no database migration. Landscaping remains version 1.0.0 and
ships with Bold Outdoors as its default plus the three selectable alternate
themes.
