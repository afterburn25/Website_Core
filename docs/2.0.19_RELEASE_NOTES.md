# Website Core 2.0.19

Version 2.0.19 completes the commercial-hardening pass for SEO, Redirects,
Translations, and Layout Patterns. It does not add a new product area or a
database migration; it closes workflow, validation, ownership, and interface
gaps in the existing Core tools.

## SEO and redirects

- SEO now owns the single authoritative Redirect Manager. Navigation links to
  it instead of presenting a duplicate editor.
- Administrators can create, edit, remove, search, import, and export redirect
  maps, review traffic counts, and turn a recorded 404 into a permanent
  redirect.
- Import remains limited to 2 MB and 2,000 data rows. Invalid and conflicting
  records are skipped and the first actionable row error is reported.
- Existing source normalization, status-code allowlisting, external URL
  checks, self-redirect protection, loop detection, and audit history remain
  enforced.
- The published-page audit now checks missing/short/long search titles,
  descriptions, malformed canonical URLs, intentional noindex state, invalid
  schema or visual-block JSON, missing image alternatives, and generic links.

## Translations

- A new workspace shows source-page count, live-language count, total
  translations, and per-language completion.
- Languages may be hidden without deleting work. Hidden languages stop
  resolving publicly and disappear from translated navigation and alternate
  metadata until re-enabled.
- The editor presents source and localized content side by side, includes a
  live localized search preview, and preserves the administrator's submitted
  values when validation fails.
- Visual-block and structured-data JSON are validated before storage.
- Individual translated variants may be removed without changing the source
  page or any other language.

## Layout Patterns

- Patterns are displayed as responsive visual cards with ordered block
  previews and client-side name/block-type search.
- Administrators may apply, rename, duplicate, or delete a pattern with
  explicit conflict and missing-record handling.
- Applying remains safe: Core first writes the current page to revisions,
  installs the pattern layout, and returns the destination page to draft.

## Upgrade and compatibility

- No schema migration is required. Existing redirect, language, translation,
  page-pattern, page-revision, and page metadata records remain in place.
- Upload the 2.0.19 repair package over an installed 2.x site or use a 2.0.19
  complete/bundled installer for a new site.
- PHP 8.4/8.5 and native MySQL 8.4/MariaDB 11.4 remain the release matrix.
- Packaged browser verification on a real subfolder/shared-host installation
  remains the external acceptance gate documented in
  `docs/COMMERCIAL_HARDENING.md`.
