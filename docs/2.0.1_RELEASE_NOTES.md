# Website Core 2.0.1

## Navigation Menu visibility

The Core-owned **Website** administration category now labels the visual menu
editor **Navigation Menu**. The editor identifies its primary tree as the links
shown in the public website header.

## Existing catering navigation becomes editable

Module API v1 now provides `navigationMenu()` and `navigationTree()`: each
industry module declares the starting navigation suited to its website, then
Core imports and manages the editable copy. Catering module `0.1.16` uses this
contract to initialize its six approved existing header links when the primary
menu has no stored items. This is a one-time upgrade/install action:

- Existing customized Core menus are never replaced.
- The initialized links immediately appear in the visual tree editor.
- The catering header renders the stored order and nesting.
- Same-tab, new-tab, and new-window choices are honored.
- After initialization, an administrator may intentionally remove every link
  without the module recreating the defaults.

There is no Core schema migration in 2.0.1. The two navigation methods are a
backward-compatible addition to Module API v1; the package manifest schema
remains version 1. Catering `0.1.16` requires Core `>=2.0.1,<3.0.0`.
