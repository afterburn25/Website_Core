# Website Core 2.0.20

Version 2.0.20 completes the commercial-hardening pass for Appearance and the
Core public-theme contract. It adds no industry-specific behavior and requires
no schema migration.

## Appearance workspace

- Rebuilds Appearance as a responsive brand workspace with current-state
  summaries, direct logo/favicon/social-image uploads, Media selection, guided
  layout controls, and an immediate representative preview.
- Preserves colors, layout choices, copyright text, and social URLs when a
  validation error sends the administrator back to the form.
- Displays installed themes as visual cards and refuses to activate a theme
  whose manifest, Core requirement, or package contract is incompatible.

## Public theme contract

- Loads the base stylesheet plus the active child theme's declared CSS and JS
  assets through Core's constrained, subfolder-safe asset route.
- Accepts both the documented `parent` manifest property and legacy `extends`
  property when resolving template inheritance.
- Adds complete baseline Open Graph metadata, social-card selection, and an
  accessible responsive primary-menu control with Escape and link-close flows.
- Keeps Core's required Cajun Web Pro attribution protected independently of
  theme templates and editable business copyright text.

## Upgrade and compatibility

- Existing branding, media, theme, social, menu, and design settings remain in
  place. No database migration is required.
- Upload the 2.0.20 repair package over an installed 2.x site or use a 2.0.20
  complete/bundled installer for a new site.
- PHP 8.4/8.5 and native MySQL 8.4/MariaDB 11.4 remain the release matrix.
