# Website Core 2.0.21

Version 2.0.21 completes the commercial-hardening pass for administrator
accounts, roles, profiles, sessions, and multi-factor authentication. No schema
migration is required.

## Administrator access

- Rebuilds the administrator directory around account identity, role, status,
  MFA coverage, last sign-in, password reset, and safe enable/disable actions.
- Retains valid account-creation fields when validation fails and rejects
  duplicate usernames and email addresses.
- Enforces `admins.manage_nonowner` on non-owner enable/disable requests and
  makes last-owner checks and account updates one transaction.

## Roles and profiles

- Presents protected built-in roles, assignment counts, and grouped human
  explanations for every Core or module capability.
- Adds self-service username/email updates with uniqueness checks and audit
  evidence.
- Rebuilds session review as a device-oriented workspace with individual and
  all-other-session revocation.

## MFA recovery

- Adds cancellable enrollment, one-time recovery-code display/copy, remaining
  code counts, and password-confirmed regeneration.
- Regeneration invalidates every old recovery code and other active session.
  Disabling MFA removes recovery codes and other sessions as well.
- Security posture now summarizes MFA coverage, policy, active sessions,
  enabled owners, and per-account recovery readiness.

Existing administrators, roles, sessions, MFA secrets, and recovery codes
remain compatible with 2.0.21.
