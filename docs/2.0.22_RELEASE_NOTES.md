# Website Core 2.0.22

Version 2.0.22 completes Privacy and Integrations. It adds one additive,
driver-portable migration for privacy verification and resolution evidence.

- Visitors can reopen privacy choices, switch back to essential-only storage,
  and reach a polished request center that retains invalid submissions.
- Optional analytics cannot be configured without the explicit-consent UI.
- Privacy requests now move through new, identity-verified, and completed
  states with timestamps, resolution notes, reopening, audited CSV export, and
  spreadsheet-formula protection.
- API credentials remain scoped and one-time-visible; active keys can now be
  safely rotated, which creates a replacement before revoking the old token.
- Webhooks can be edited, tested, enabled/disabled, retried, and have their
  HMAC signing secret rotated. New secrets remain one-time-visible.
- Site transfer imports are capped at 5 MB and continue to exclude
  credentials, administrator identities, submissions, and private data.
