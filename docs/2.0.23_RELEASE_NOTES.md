# Website Core 2.0.23

Version 2.0.23 completes Modules and Marketplace without changing the package
format or database schema.

- Modules summarizes enabled, staged, and attention-needed packages and adds
  responsive type/attention filtering while continuing to present `core/base`
  as a protected built-in component.
- Recovery-mode flag creation/removal now verifies filesystem results and gives
  actionable shared-host File Manager guidance instead of reporting success
  when storage ownership blocked the change.
- Purge rejects malformed package identifiers before deriving any data prefix;
  uninstall remains file-only and purge remains separate and typed-confirmed.
- Marketplace catalog sources reject duplicates, can be disabled/re-enabled,
  and can only be removed after disablement.
- Catalog trust, archive inspection, dependencies, lifecycle journaling,
  upgrade rollback, data preservation, and Core protection remain enforced.
