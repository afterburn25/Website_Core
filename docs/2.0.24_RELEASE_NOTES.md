# Website Core 2.0.24

Version 2.0.24 completes Backups and Operations without a schema migration.

- Every listed recovery point is inspected and labeled verified/invalid with
  Core version, table count, protected-file count, size, and actionable error.
- Backup creation now fails on unreadable required files or unwritable staging
  instead of silently producing an incomplete archive.
- Local backup success is audited even when optional remote replication fails.
  Delete and restore maintenance-flag failures report truthful guidance.
- Restore still requires an owner, a successful pre-restore safety snapshot,
  full checksum validation, matching driver/prefix, and exclusive lock.
- Operations prevents duplicate pending backup jobs, records cron heartbeat,
  and exposes explicit recovery of expired worker leases into uncertain state.
- Maintenance-mode file ownership failures now remain visible instead of
  incorrectly claiming the public site changed state.
