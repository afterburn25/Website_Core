# Website Core 2.0.25

Version 2.0.25 completes Health, Core Updates, Audit, and Settings without a
schema migration.

- Fixes Audit to use the canonical `actor_id`/`context` schema, restoring real
  history, search, event-family filters, timeline presentation, and a bounded,
  spreadsheet-safe CSV export.
- Binds update review to the staged archive SHA-256, rechecks it before apply,
  supports explicit discard, and rolls replaced files back if migrations fail.
- Keeps update GET metadata-only and failure-safe; signatures, archive safety,
  protected paths, hashes, downgrade/replay gates, exclusive lock, backup, and
  migration audit remain enforced.
- Settings validates HTTPS URL, identity, locale, mail sender, SMTP host/port,
  encryption, and credentials before changing any values; non-secret entries
  survive validation errors.
- The browser-cron token can be deliberately rotated, and Health now surfaces
  HTTPS state, required PHP extensions, and the cron heartbeat.
