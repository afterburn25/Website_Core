# Website Core 2.0.27

Released: 2026-10-24

## Installer and reinstall completion

- Adds a setup-specific CSRF token and strict secure/HTTP-only/SameSite claim
  cookie so only the claimed browser can test or submit credentials.
- Serializes installation submissions with a non-blocking operation lock to
  prevent double-click and concurrent initialization races.
- Makes existing Website Core database reuse explicit: the database test
  detects the schema and setup requires a protected-reinstall confirmation.
- Preserves a recoverable existing application key during repair/reinstall so
  encrypted integration credentials remain readable.
- Validates canonical HTTPS URLs and field lengths, maps database failures to
  safe actionable messages, and prevents raw driver errors reaching setup.
- Verifies generated configuration in a temporary file before atomic commit
  and writes the permanent completion marker atomically.
- Adds the cleanup recheck action directly to the completion warning while
  retaining separate website and admin launch actions.

## Upgrade notes

No database migration is required. These changes affect installer and repair
behavior; established installations retain their current configuration.
