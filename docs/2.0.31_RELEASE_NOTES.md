# Website Core 2.0.31

Release candidate: 2026-10-25

## Administration workflow completion

- Aligns every field in **Add a managed site**, including the write-only
  remote API key, through a dedicated responsive grid.
- Replaces the overflowing 404-insights table action cell with responsive
  issue cards. Traffic, timestamps, page selection, redirect creation, and
  dismissal remain visually attached to the correct missing path.
- Makes incomplete legacy 404 records readable with explicit `0 visits` and
  `Never` values.
- Identifies the signed-in administrator on Security and provides a direct MFA
  setup action when that account is not protected.
- Selects standard SMTP ports when encryption changes: 587 for TLS/STARTTLS,
  465 for implicit SSL/TLS, and 25 for a plain connection. Deliberately custom
  ports are preserved.
- Adds an SMTP connection test that uses the displayed unsaved values, performs
  the server handshake and authentication, sends no message, saves no values,
  omits the password from audit data, and retains non-secret entries on return.

## Forms workspace

- Presents one consistent three-step flow: set up the form, add visitor fields,
  then save and place it through a page Form block.
- Expands the workflow guide and editing canvas, strengthens hierarchy, and
  keeps the public preview beside the field editor when space permits.
- Adds editable Contact, Quote request, and Event enquiry starter field sets.
- Retains drag ordering, keyboard arrow controls, validation, notification,
  pause/reactivate, inbox, status, and export behavior.

## Compatibility

No database migration, module API change, or module version change is needed.
The shared-host recovery acceptance introduced in 2.0.30 remains the next live
gate after this package is uploaded.
