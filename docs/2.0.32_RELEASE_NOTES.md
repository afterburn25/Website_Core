# Website Core 2.0.32

Core 2.0.32 adds the reusable first-party analytics system originally proven
on Spiritual Gorillaz. Analytics is now a Core responsibility, so every
industry module receives the same reporting automatically.

## Owner workspace

- Dedicated Analytics navigation with Dashboard, Visitor Explorer, and
  Geography screens.
- Seven-, 30-, 90-, or custom date ranges up to 366 days.
- Visitors, pageviews, live visitors, completed-session bounce rate, visible
  active time, popular pages, acquisition channels, referrals, campaigns,
  search terms, device/browser/OS, session depth, engagement, entry and exit
  pages, and weekly hour activity.
- Anonymous journey detail with 25 visits per page and up to 100 events per
  visit, plus filters for dates, channel, status, country, device, browser,
  operating system, referrer, and visited page.
- Crawler traffic is collected and reported separately, never mixed into
  human visitor totals.
- Search Console CSV import accepts the standard Top queries, Clicks,
  Impressions, CTR, and Position columns (2 MiB and 5,000-row limits).
- CSV visitor export is owner-only, audited, formula-injection safe, and
  limited to 25,000 rows per export.

## Privacy behavior

- No raw IP address, full user-agent string, visitor name, account identity,
  or form information is stored.
- Anonymous visit identifiers are installation-keyed hashes with a 30-minute
  inactivity boundary.
- DNT and Global Privacy Control are honored. Signed-in administrators,
  previews, prefetches, HEAD/non-GET requests, error responses, assets,
  media, forms, privacy endpoints, APIs, and admin routes are excluded.
- Only external referrer domains are saved; complete referring URLs are not.
- UTM values and supplied search terms are length-bounded and sanitized.
- Visible-tab active time uses a bounded same-origin heartbeat. Live means
  activity within the preceding 60 seconds and refreshes every 15 seconds.
- Approximate geography uses trusted host-provided local GeoIP headers when
  available and never calls an external location API.

## Upgrade notes

Migration `2026_10_25_0028` creates four additive tables. Existing sites run
it automatically on first request after the new files are uploaded. Collection
defaults on, crawler separation defaults on, geography defaults on when the
host supplies data, and retention defaults to 90 days. Owners can pause each
collection area and choose 30, 90, 180, or 365 days from Analytics.

The existing cron entry now performs bounded retention cleanup. No additional
scheduled task, module update, external account, or API key is required.

## Transactional email test repair

The SMTP connection and test-delivery controls now live at the bottom of the
Transactional email panel. Both run in place, show precise success or failure
feedback without reloading Settings, and enforce a short connection deadline.
Even when the hosting proxy returns a non-JSON gateway response, the current
page remains open and reports the HTTP or timeout failure beside the buttons.
