# Website Core 2.0.4

## Maintenance-mode administrator access repair

Core 2.0.4 fixes a lockout found during shared-hosting testing. Previously,
maintenance mode exempted the literal login and password-recovery routes but
intercepted `/admin` before its authentication middleware could redirect a
logged-out administrator to the login screen.

The complete `/admin` namespace now bypasses only the **public maintenance
intercept**. Normal administrator authentication, MFA enforcement, CSRF
protection, roles, and capability checks remain active. Consequently:

- `/catering/admin` can redirect to the login page after logout;
- the maintenance page's discreet lock icon reaches a working login screen;
- authenticated administrators can manage and disable maintenance mode; and
- ordinary public pages remain unavailable with the branded HTTP 503 page.

An automated regression test covers root and nested admin routes, public
routes, subfolder deployment, and the rewrite-independent login redirect.
There is no database migration and no Module API change.
