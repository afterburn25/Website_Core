# Website Core 2.0.7

Released 2026-10-24.

## Brand presentation

- Enlarges the installed site logo in the administration sidebar.
- Places the logo above a single-line **Website Administration** label.
- Removes the repeated site-name text from the administration brand block.
- Removes the opaque logo frame so transparent module logos blend into the
  administration sidebar.
- Removes the catering footer logo's boxed background while retaining the
  original transparent PNG artwork.

## Social profiles

- Expands Website → Appearance from six to fifteen ready-to-use social and
  local-business profiles, each with a dependency-free icon preview.
- Replaces repetitive per-profile placement controls with one clear dropdown
  for Header, Footer, or Header and footer.
- Keeps profiles with blank URLs out of all public markup and safely adapts
  legacy per-profile placement settings during an upgrade.

## Bundled catering module

- Updates the bundled catering module to `0.1.21` for the transparent footer
  logo presentation.
