# Website Core 2.0.9

Released 2026-10-24.

## Core Updates workspace recovery

- `/admin/updates` remains available when `storage/staged-update.zip` is
  missing, unreadable, invalid, stale, or cannot be deleted by PHP.
- Invalid staged files are removed when permissions permit. If cleanup is
  blocked, the administrator receives the exact manual path to remove.
- Update-journal reads now tolerate missing and unreadable host files.
- Unexpected storage inspection failures are logged server-side and rendered
  as a recoverable administrator warning. No live Core files are changed.

## Shared-host deployment

The per-industry `REPAIR-UPLOAD` artifact remains installer-free and preserves
runtime configuration, storage, uploads, and database data. Extract it at the
installed web root and allow existing files to be overwritten.
