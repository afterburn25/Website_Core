# Website Core 2.0.0

## Agency operations

- The owner-only Agency dashboard registers remote Website Core sites using a
  scoped `health.read` credential. Remote credentials are encrypted with the
  installation app key and never displayed after entry.
- Authenticated checks report site identity, core version and installed
  industry-module versions, with errors and last-check time retained locally.

## Trusted distribution

- Marketplace sources are public HTTPS JSON catalogs signed with an Ed25519
  key already present in `trust.public_keys`. Unsigned feeds fail closed.
- Catalog entries expose industries, add-ons and themes while managed core
  releases can be staged or applied according to explicit security/all
  policies. Downloads are size-bounded, checksum-verified, then independently
  inspected as signed Website Core update archives.
- Automatic apply creates a full recovery backup and maintenance flag before
  changing code, then runs migrations and records the outcome.

## Professional navigation editor

- Navigation is displayed as its real nested tree. Links can be dragged onto
  one another to create submenus, reordered visually, or moved through
  accessible up/down/indent/outdent controls before saving.
- Links can follow a Website Core page selected by name (and continue to work
  if its slug changes), or use an internal/external custom URL.
- Each link can open in the same tab, a new tab, or a dedicated new window;
  the active theme honors the stored behavior with safe `noopener` handling.

Migration `2026_10_23_0021` is additive. Product version 2.0 does not break
the extension contract: `WC_API_VERSION` and package manifest schema remain 1.
