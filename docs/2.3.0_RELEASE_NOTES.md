# AllWebPro Core 2.3.0

Core 2.3.0 completes the reusable `adminResource()` record workspace started
in 2.2. Industry modules may opt into visible-row ordering and a declared map
of bulk actions without rebuilding selection controls, validation, permission
checks, CSRF protection, confirmation, feedback, or audit plumbing.

The optional final `$options` argument accepts:

- `reorder`: callback receiving the visible record IDs in submitted order;
- `bulk`: callback receiving selected IDs and the declared action token; and
- `bulk_actions`: safe action-token to administrator-label mappings.

Core accepts only unique positive integer IDs, limits each request to 100
submitted values, rejects undeclared bulk actions before callbacks run, and
records successful actions against the package and resource. Modules continue
to own persistence, transactions, record authorization, and business rules.
Ordering intentionally submits only the current page because filtered and
paginated workspaces cannot safely assert a complete package-wide order.

The shared view adds select-all controls, keyboard-reachable up/down ordering,
responsive action presentation, confirmation, and clear success/error states.
Existing `adminResource()` registrations remain source compatible because the
new options argument is last and defaults to an empty array.

No database migration or industry-module synchronization is required. GitHub

`861d1b3e3c8def4ed4bb0b9e29614ad4290663a5`, including PHP 8.4/8.5,
