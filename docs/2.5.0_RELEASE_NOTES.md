# AllWebPro Core 2.5.0

Core 2.5.0 connects industry modules to the existing shared Forms and
transactional notification platform without creating module-specific inboxes,
mail queues, or duplicate public submissions.

## Delivered

- `ModuleContext::starterForm()` creates a package-attributed starter schema
  once. Later boots and upgrades retain administrator field, recipient,
  template, availability and confirmation-message changes.
- `adopt_id` attaches an existing Core form and its submission history to a
  package during a deliberate migration instead of seeding a duplicate.
- Package validators run after Core field validation and before storage.
  Field-keyed errors reuse the shared public error result; a validator failure
  fails closed without losing entered values.
- New submissions fire fault-isolated `form.submitted` events and an optional
  package handler with the protected submission ID, package/form identity and
  cleaned data.
- `formSubmission()` exposes only the caller's package partition.
  `linkFormSubmission()` records idempotent links to module-owned records.
- Package-owned forms fail closed when their package is disabled, removed or
  quarantined, so industry validation cannot be bypassed while code is absent.
- Public forms include a one-time request token. Database uniqueness makes a
  browser retry return the original submission without firing another event
  or notification.
- Core notification templates support field tokens plus `form_name`,
  `submission_id`, and `submitted_at`. Queue status and delivery errors remain
  visible in the shared submission inbox.
- Explicit package purge removes package forms, links, submissions and their
  notification records. Disable and uninstall continue to preserve data.

## Compatibility and upgrade

- Core version: `2.5.0`
- Module API: `1` (backward compatible)
- Schema: additive migration `2026_10_25_0031`
- Existing administrator-created forms remain unowned and continue working.
- Existing packages require no change. Adoption must be deliberate, and an
  existing form is attached only when its exact `adopt_id` is declared.
