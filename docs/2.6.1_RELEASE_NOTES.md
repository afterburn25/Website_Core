# Website Core 2.6.1

Core 2.6.1 corrects the administration experience for the shared service-area
contract delivered in 2.6.0. It is a backward-compatible maintenance release
with no database migration and no Module API change.

## Delivered

- Adds **Website → Geo service area** when an enabled module declares the
  `business.service_area` feature.
- Provides explicit City, State / region, optional Country and Range from city
  (miles) inputs instead of exposing analytics date controls as Geo setup.
- Keeps the audience geography report under Analytics but renames it to
  **Audience locations**, where From and To continue to describe the report's
  date range.
- Links the shared Business profile to the dedicated Geo settings screen and
  shows the current verified center and mileage range.
- Preserves the last verified coordinates if a new provider lookup fails,
  while retaining the submitted values on screen for correction.

## Compatibility

- Module API remains version 1.
- Schema remains `2026_10_25_0032`.
- Existing verified service-area settings remain valid.
- Enabled modules continue to own the server-side geocoding provider and can
  reuse Core's map and address-validation services without exposing provider
  credentials.
