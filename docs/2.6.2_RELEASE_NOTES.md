# Website Core 2.6.2

Released 2026-10-26.

## Module administration navigation

- `ModuleContext::adminPage()` now accepts an optional fifth `icon` argument.
- `ModuleContext::adminResource()` accepts the same declaration through its
  `options.icon` value.
- Safe lowercase icon tokens are carried into Core's shared administration
  navigation instead of forcing every module destination to use the generic
  module icon.
- Existing modules remain compatible and continue to receive the `modules`
  fallback when they do not declare an icon.

## Industry theme chooser

- Module theme variants may declare a safe packaged thumbnail.
- Appearance presents visual theme cards with one color-palette dropdown and
  one Activate action per theme; activation publishes the selected layout,
  palette, and optional image overrides in one transaction.
- The previous generic layout-collection wording and multi-form
  palette grid are removed from the administrator-facing experience.

## Deployment note

When module files are replaced through a hosting file manager, open
**Administration → Modules** and select **Finalize update** for that module.
This runs its pending migrations and synchronizes the database version; merely
copying a combined archive over an installed site does not perform that step.
